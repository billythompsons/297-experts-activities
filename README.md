# 297 each in 501

The vision: every one of the 501 BostonDeveloper products grows toward carrying the full 297-feature set. This folder is the canonical 297 - the complete feature catalog, mapped against the 5 pricing plans, so you can browse exactly what each plan unlocks.

## The five plans (cumulative)

| Plan | Price | Unlocks | Running total |
|---|---|---|---|
| Free | $0/mo | 12 features | 12 of 297 |
| Starter | $5/mo | 28 features | 40 of 297 |
| Pro | $19/mo | 55 features | 95 of 297 |
| Accelerator | $134/mo | 81 features | 176 of 297 |
| Studio | $200/mo | 121 features | 297 of 297 |

12 + 28 + 55 + 81 + 121 = 297. Each plan includes everything below it.
